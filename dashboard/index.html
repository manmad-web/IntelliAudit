A workspace for expert review

Filter a dataset, select a case, and compare its statement and transaction evidence with the proposed answer key.

  1. Inspect the statement. Switch to the corrected version to check the proposed change. Highlighting uses each version’s own row numbers; missing rows are described in the answer key.
  2. Validate the answer. Check the judgement, affected line, governing paragraph, and rationale. “Expert authored · unvalidated” is a dataset label, not accountant approval.
  3. Record your decision. Approve the proposed answer, flag it for follow-up, or reject it and document your alternative.

Notes and decisions are stored in this browser for this dataset version. Export them to back up or share your work; import an export to continue in another browser. Export includes only saved reviews, across all filters in the current dataset.

Amounts use the currency and scale shown on each case. This reviewer intentionally exposes benchmark labels and is separate from blind model evaluation.
